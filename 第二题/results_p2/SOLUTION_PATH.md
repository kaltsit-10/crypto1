# Problem 2 求解全记录

## 问题
非齐次 SIS: 找 v, u ∈ Z^100，||v||_∞ ≤ 15, ||u||_∞ ≤ 15，满足 Av + u ≡ t (mod 100)。

## 唯一有效的三步

### 第一步：BKZ-80 格基归约 ✅

构造正确的 SIS 格基（200×200）：
```
B = [I_100,  -A^T]
    [0,      q·I_100]
```

关键: 必须有负号 `-A^T`，否则格向量不满足 Av+u≡0。

用 fpylll BKZ-80 归约（strategies=default.json, max_loops=2），耗时 3h23m。
结果: 齐次最佳 score=14（3 行 ≤15）。基文件: `bkz80_p2_basis_v2.npy`。

### 第二步：Babai CVP → 初始解 score=24 ✅

在 BKZ-80 基上做 Babai 最近平面算法，得到初始候选解:
- ||v||_∞ = 24, ||u||_∞ = 19, score=24
- 仅 6 个坐标超标（5 个 v, 1 个 u）

### 第三步：B&B GSO 剪枝枚举 → score=15 ✅ ← 关键突破

**原理**: Babai 算法的取整误差集中在最后几个 GSO 维度。对于 BKZ-80 基：
- 前 192 维 GSO 范数大（~q=100），Babai 取值准确
- 后 8 维 GSO 范数小，但 μ 系数将误差反向传播到全部 200 个坐标

**做法**:
1. 获取 Babai 系数 c_j（j=0..199）
2. 枚举最后 8 个系数（j=192..199）的邻域，每个 ±4
3. 每种组合: 用修正系数重建 v，计算 u = centered((t - A·v) % q)
4. 剪枝: 若当前分支的 GSO ℓ₂ 下界 > 当前最优 ℓ₂，跳过
5. 对剩余维（0..191）仍用 Babai 取整

**参数**:
- 搜索维度: K=8
- 系数范围: ±4
- 总组合: (2×4+1)^8 = 9^8 = 43,046,721
- 剪枝策略: GSO ℓ₂ 残差下界

**过程**:
```
Babai 起点:  score=24 → 23 → 22 → 20 → 18 → 17 → 16 → 15
```

每个 score 都是一个独立发现的改进解，B&B 在中间节点就找到了。
**6 分钟跑完 4300 万组合。**

**输出**: `results_p2/solution_p2_20260521_220739.txt`

### 验证 ✅

```
(A·v + u - t) % 100 == 0    (全零)
||v||_∞ = 15, ||u||_∞ = 15
score = 15 (恰好压线)
```

## 为什么这才有效

| 之前试的方法 | 为什么失败 |
|-------------|-----------|
| G6K workout (bs=40-80) | 改善格基不直接帮助 CVP |
| 模拟退火/随机扰动 | 无 GSO 结构引导，扰动几乎必炸 |
| 贪心坐标下降 | 近视——需多系数协调变化 |
| LLL+Kannan | u 公式 bug，修正后 best=44 |
| fpylll CVP exact | 搜 200 维全空间，4h 无结果 |
| Z3/CP-SAT | 200 变量太大，超时 |

**B&B 做对了两件事**: (1) 搜对了方向——最后 8 个 GSO 系数；(2) 剪对了枝——GSO ℓ₂ 下界而非 ℓ∞ 上界。

## 核心教训

1. **约束验证不可省**: `u = centered((t - A·v) % q)`，**不是** `centered(u_lat)`
2. **B&B 比精确 CVP 快**: 8 维 ±4 的 43M << 200 维全枚举
3. **GSO 剪枝必须用 ℓ₂**: ℓ∞ 剪枝在根节点就剪光一切
4. **Babai 误差集中在最后几维**: BKZ 归约越好，这个效应越明显
